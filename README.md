# Capella87 Capellatap

## How do I install these formulae?

`brew install capella87/capellatap/<formula>`

Or `brew tap capella87/capellatap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "capella87/capellatap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
